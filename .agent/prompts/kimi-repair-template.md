你正在同一个隔离工作树中修复上一轮实现。仍然只允许修改 `web/`，不得提交、推送、修改 Git 历史或扩大任务范围。

## 原任务

填写任务 ID 与目标。

## Codex 验收失败证据

粘贴最小、已脱敏的失败命令、错误摘要和相关文件位置。不要粘贴 Token、Cookie、私钥、`.env` 内容或完整生产日志。

## 本轮要求

1. 先确认根因，再做最小修复。
2. 补充能复现该问题的测试，或解释为什么现有测试已覆盖。
3. 重新运行失败命令及最小相关回归。
4. 输出修改文件、验证结果和剩余风险。
5. 不修改 `web/` 以外的任何文件。
