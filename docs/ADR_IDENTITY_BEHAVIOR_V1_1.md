# 九章 WDSP 身份与行为防护 V1.1 ADR

## 目的

记录 V1.1 身份识别、枚举检测和管理面契约的实现决策，避免开发任务拆分与现有 WDSP 数据面产生隐式冲突。

## 决策

1. **复用现有链路**：身份解析复用 `RequestContext` 与 `jiuzhang_guard` 请求处理链，事件仍通过 `identity-events.log` 断点采集器入库；不新增旁路网关或网络调用。
2. **身份类型与置信度**：统一类型为 `HUMAN/BOT/APPLICATION/SERVICE/MACHINE/AGENT/UNKNOWN`。置信度为 0–100，证据仅保存脱敏标签，禁止记录 token、Cookie、原始账号/对象值。
3. **枚举检测**：账号/对象标识值使用 HMAC 脱敏后进入有界集合计数；分页、批量查询和配置排除字段不计入枚举。计数超过策略阈值后只生成 `OBSERVE` 信号，不直接阻断。
4. **兼容与容错**：新增字段采用幂等迁移并提供默认值；网关行为策略关闭或 Valkey 不可用时保持 fail-open，旧事件/旧配置可继续读取。
5. **版本与回滚**：身份契约字段由迁移 `000116` 管理，行为策略及事件扩展由 `000117` 管理；下行策略携带版本号，回滚仅回滚配置快照，不恢复敏感证据原文。

## 非目标

V1.1 不开放行为信号的阻断动作、不引入新的身份存储基础设施，也不改变既有 CC/WAF 规则优先级。
