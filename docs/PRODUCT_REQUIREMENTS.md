# 产品需求文档

## 产品名称

九章WEB应用智能防护系统 V2.0

## 产品定位

一套自主研发的反向代理型 Web 应用防火墙（WAF）管理系统，为政府、企事业单位、中小型网站及内部业务系统提供 Web 应用统一接入、攻击检测、防护处置和审计报告能力。

## 目标用户

- 政府、企事业单位安全运维人员
- 中小型网站管理员
- 业务系统安全负责人
- 内部应用运维团队

## 核心需求

### 1. Web 应用接入

- 支持 HTTP/HTTPS 反向代理
- 支持多域名、多端口接入
- 支持多源站负载均衡
- 支持源站健康检查
- 支持 HTTPS 证书管理

### 2. 攻击检测与防护

- SQL 注入检测
- XSS 检测
- 命令执行检测
- 文件包含检测
- 路径穿越检测
- 协议异常检测
- 恶意文件上传检测
- 扫描器特征检测

### 3. 访问控制

- IP 黑白名单
- CC 攻击防护
- 高频访问限制
- 真实客户端 IP 识别
- 可信代理配置

### 4. 安全事件管理

- 安全事件记录与查询
- 事件详情展示
- 事件处置流程
- 误报例外策略
- 事件导出

### 5. 策略管理

- 防护模式（关闭/观察/防护）
- 防护策略模板（宽松/标准/严格）
- CRS 规则管理
- 自定义规则
- 例外策略

### 6. 报表与态势

- 安全态势首页
- 攻击趋势分析
- 攻击类型分布
- 攻击源 IP 排行
- 安全报表生成（HTML/PDF）

### 7. 系统管理

- 三权分立用户体系
- 操作审计
- 配置版本管理
- 配置发布与回滚
- 系统备份恢复

## 非功能性需求

### 性能

- 网关转发性能：500 RPS 以上
- 新增 P95 延迟：不高于 30ms
- 错误率：低于 0.1%
- 管理接口 P95：低于 500ms

### 安全

- 密码 Argon2id/bcrypt 加密
- HttpOnly Secure Cookie
- CSRF 防护
- 私钥加密存储
- 日志脱敏
- SSRF 防护
- 配置注入防护

### 可靠性

- 发布失败不影响现有配置
- 配置可回滚
- 重启后恢复最后有效配置
- 数据定期备份

### 可维护性

- 模块化单体架构
- 完整测试覆盖
- 详细审计日志
- 配置版本追踪

## 约束

- 不复制任何现有 WAF 产品代码
- 优先使用 Apache-2.0/MIT/BSD 组件
- 禁止使用 GPL/AGPL 组件（未经批准）
- 所有版本明确锁定
- 阶段化交付，V2.0 不提前扩展未来功能
