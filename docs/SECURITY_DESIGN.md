# 安全设计文档

## 管理面安全

1. **端口分离**：管理端和业务代理端口分离，管理端默认只监听内网；
2. **身份认证**：所有接口执行身份认证；
3. **权限控制**：所有写接口执行后端权限校验和 CSRF 校验；
4. **配置校验**：所有进入网关配置的字段经过白名单校验；
5. **数据库权限**：使用最小权限账号；
6. **Valkey 安全**：禁止公网暴露，必须配置访问密码；
7. **Caddy Admin API**：仅通过 Unix Socket 访问，不暴露到业务网络；
8. **文件上传**：限制大小和类型；
9. **私钥保护**：证书私钥加密存储，日志不打印私钥；
10. **日志脱敏**：敏感字段默认脱敏；
11. **错误处理**：接口错误不返回堆栈；
12. **调试接口**：生产环境关闭；
13. **安全响应头**：配置默认安全响应头；
14. **限速**：登录和高风险接口限速。

## 身份认证安全

- 密码使用 Argon2id 或 bcrypt 存储；
- 不允许明文密码；
- 访问令牌使用 HttpOnly、Secure、SameSite Cookie；
- 不保存于浏览器 LocalStorage；
- 所有写操作执行 CSRF 校验；
- 登录错误不区分用户名不存在和密码错误；
- 连续登录失败次数和锁定时间可配置。

## 配置注入防护

所有可进入网关配置的字段必须经过白名单校验。

禁止直接把用户输入拼接到：

- Caddyfile；
- SecLang 规则；
- Shell 命令；
- 文件路径；
- SQL；
- HTML 阻断页面；
- Docker 命令。

使用结构化配置生成器，不依赖字符串模板无条件拼接。

## SSRF 防护

源站连通性测试必须防止访问：

- Caddy 管理接口；
- 管理后端接口；
- Docker Socket；
- 云主机元数据地址；
- 本机回环管理服务；
- Valkey 和 PostgreSQL；
- Unix Socket；
- `file://` 等非 HTTP 协议。

允许管理员显式配置合法内网源站，但必须经过地址解析、端口校验和审计。

## 日志隐私

默认脱敏字段：

- Authorization；
- Cookie；
- Set-Cookie；
- 密码参数；
- Token；
- 身份证号；
- 银行卡号；
- 私钥；
- 会话标识。

安全事件只保留调查所需信息，不默认保存完整请求体和响应体。

## 数据安全

- 证书私钥在数据库或磁盘中加密保存；
- 私钥文件权限不得高于 `0600`；
- 备份文件中的私钥必须加密；
- 删除证书前必须检查绑定关系。

## 网关安全

- Caddy Admin API 仅通过 Unix Socket 访问；
- 配置发布失败不影响当前有效配置；
- 重启后恢复最后有效配置；
- 真实客户端 IP 识别基于可信代理列表；
- 不无条件信任 X-Forwarded-For。

## 审计安全

- 审计日志不允许通过普通业务接口删除；
- 高风险操作记录操作前值、操作后值、操作人和时间；
- 敏感数据查看记录审计。

## 安全测试要求

至少执行：

- 身份认证测试；
- 越权测试；
- CSRF 测试；
- XSS 测试；
- SQL 注入测试；
- SSRF 测试；
- 文件上传测试；
- 配置注入测试；
- 命令注入测试；
- 敏感信息泄露测试；
- 弱口令测试；
- 会话固定测试；
- 日志伪造测试；
- 依赖漏洞扫描；
- 容器配置检查。
