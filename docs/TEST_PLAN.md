# 测试计划

## 测试策略

- 单元测试：Go Test、Vitest
- 接口测试：Go Test + httptest
- E2E 测试：Playwright
- WAF 回归测试：go-ftw

- 安全测试：手动 + 自动化工具

## 性能测试

### 网关性能

测试环境：

```text
4 核 CPU
8GB 内存
本地 SSD
单网关节点
简单 HTTP 源站
```

目标：

- 500 RPS 以上稳定转发
- 200 并发下无异常崩溃
- 开启标准 WAF 策略后，新增 P95 延迟不高于 30 毫秒
- 错误率低于 0.1%
- 连续压力测试无持续内存增长
- 单个超大请求不能导致网关内存耗尽

### 管理系统

- 普通列表接口 P95 低于 500 毫秒
- 首页聚合接口 P95 低于 1 秒
- 安全事件写入延迟低于 5 秒
- 配置发布期间现有连接不应大面积中断
- 发布失败后原配置继续生效
- 重启后可以恢复最后有效配置
