# WDSP IP 保护硬件与 TEE 验收边界

## 目的

本文件记录当前开发验收环境对 IP-10～IP-13 的真实能力边界。它不是硬件绑定或机密计算通过证明，也不把软件级 fingerprint、容器隔离或宿主机安全特性等同于 TPM/TEE/远程证明。

## 检查记录

- 检查日期：2026-09-07（Asia/Shanghai）
- 检查平台：Apple Silicon macOS，`arm64`
- 检查结果：未发现 `/dev/tpmrm0`；未发现 `tpm2_getcap`、`tpm2_pcrread`、`virsh`；仅发现 QEMU x86_64 可执行文件。
- 未执行：Linux TDX/SEV-SNP/TrustZone 证明、TPM PCR 读取、云 vTPM、TEE 密钥释放、主备租约或离线 TEE 恢复。
- 敏感信息处理：原始硬件序列号、硬件 UUID、用户标识和其他设备标识不写入仓库证据。

## 判定边界

| 范围 | 当前状态 | 说明 |
|---|---|---|
| IP-10 硬件绑定与抗复制 | `BLOCKED` | 当前环境没有可验收的 TPM/设备密钥/硬件持有证明；现有软件 fingerprint 只能作为弱绑定。 |
| IP-11 在线机密计算 PoC | `BLOCKED` | 没有批准的 TEE 平台、证明服务和证明绑定密钥释放链路。 |
| IP-12 离线机密计算 PoC | `BLOCKED` | 没有真实 TEE 的离线激活、重启恢复、快照/回滚和密钥生命周期环境。 |
| IP-13 机密计算产品化 | `BLOCKED` | 普通升级/回滚不能替代 CC approved-version、证明策略迁移和 TEE 主备验收。 |

## 后续真实环境要求

进入这些项目的 `PASS` 验收前，必须在经批准的 Linux TPM/vTPM 或 TDX/SEV-SNP 等效环境重新执行，并保存不含密钥和客户数据的最小证据：平台/固件基线、证明报告摘要、测量值绑定、密钥释放拒绝与成功矩阵、重放/快照/回滚/主备故障结果，以及性能和资源数据。

在满足这些前置条件前，产品状态和发布文档不得显示“已启用硬件绑定”“已启用 TEE”或“已完成机密计算保护”。
