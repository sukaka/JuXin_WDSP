# 第1章 系统概述

## 1.1 产品简介

九章WEB应用智能防护系统V2.0（以下简称"本系统"）是一套反向代理型 Web 应用防火墙（WAF）管理系统。系统部署于客户端与源站之间，对进出网站的 HTTP/HTTPS 流量进行实时检测与防护，帮助用户抵御 SQL 注入、跨站脚本（XSS）、路径穿越、命令注入、扫描器探测、CC 攻击等常见 Web 安全威胁。

系统采用"管理面 + 防护网关"分离架构：管理面提供本站所述的全部管理功能（应用接入、策略配置、事件分析、报表输出、系统运维等）；防护网关部署在流量必经路径上，依据管理面发布的配置执行访问控制、频率限制、攻击检测与流量转发，二者通过配置发布机制保持同步。

## 1.2 产品架构

本系统由以下部分组成：

- 管理控制台（Web UI）：管理员通过浏览器访问的可视化管理界面，本手册全部内容均围绕管理控制台展开；
- 管理后端服务：提供 RESTful API，负责用户权限、配置管理、事件存储、报表生成等；
- 防护网关：反向代理型流量检测引擎，执行访问控制、CC 防护、Web 攻击检测与安全响应头合规处理；
- 数据存储：关系型数据库存储配置与事件数据，内存型存储提供高频计数与缓存能力。

配置生效路径为：管理员在管理控制台完成配置 → 通过「配置发布」生成配置版本 → 发布到防护网关 → 网关按新版本执行检测与转发。所有发布均有版本记录，支持回滚。

## 1.3 功能特性总览

- 应用接入与防护：网站应用接入、域名与源站管理、HTTPS 证书托管、一键启停防护；
- Web 攻击检测：内置 OWASP 核心规则集（CRS）与多规则包体系，支持自定义 SecLang 规则与例外策略；
- 访问控制：可信代理识别、IP 黑白名单、频率与 CC 防护、临时封禁；
- 事件中心：安全事件检索与处置、全量访问日志、事件统计分析；
- 安全态势：安全总览大屏、多维度统计分析、系统告警；
- 报表中心：报告任务、报告模板与报告归档，支持周期性与即时报告；
- 智能安全运营：安全助手对话、事件智能分析、攻击画像与攻击链分析、策略智能建议、自动降噪；
- 系统管理：三权分立的用户与角色体系、登录日志、操作审计、系统设置。

## 1.4 角色与权限

系统预置三类管理员角色，权限相互独立，满足三权分立要求：

| 角色 | 主要职责 | 可见功能范围 |
| --- | --- | --- |
| 系统管理员（SYSTEM_ADMIN） | 系统初始化与运维 | 用户管理、角色权限、系统设置、运行监控、存储容量、备份恢复、系统升级、交付检查、网关状态等 |
| 安全管理员（SECURITY_ADMIN） | 日常安全运营 | 网站应用、防护策略、规则库、访问控制、安全事件、报表、智能安全运营等业务功能 |
| 审计管理员（AUDIT_ADMIN） | 合规审计 | 登录日志、操作审计，以及各业务页面的只读查看 |

一个账号可绑定多个角色，可见菜单为各角色权限的并集。管理员登录后仅能看到自己权限范围内的菜单与按钮。

## 1.5 基本概念

| 概念 | 说明 |
| --- | --- |
| 网站应用 | 一个需要防护的站点或业务系统，是策略、事件、报表的归集单位 |
| 域名 | 应用对外提供访问的主机名，可配置 HTTP/HTTPS 端口与跳转 |
| 源站 | 应用的真实后端服务器（上游），网关将安全流量转发至源站 |
| 防护策略 | 一组检测模式、规则包与参数的集合，可绑定到多个应用 |
| 防护规则 | 具体攻击特征的检测逻辑，含内置规则库与自定义规则 |
| 例外策略 | 对特定请求豁免指定检测，用于消除误报 |
| 配置发布 | 将管理面配置生成版本并下发网关的动作，是配置生效的唯一途径 |
| 临时封禁 | 对触发频率限制的客户端 IP 实施的限时阻断 |

# 第2章 运行环境与登录

## 2.1 运行环境

- 客户端浏览器：Chrome 90 及以上、Edge 90 及以上（推荐 1600×900 及以上分辨率）；
- 服务端：由实施人员按部署文档完成安装后，向管理员提供访问地址与初始账号。

## 2.2 登录系统

打开浏览器，访问系统地址，进入登录页。输入用户名、密码及图形验证码，点击「登 录」按钮。验证码不区分大小写，点击图片可刷新。

[[SHOT:图2-1 系统登录页|打开系统登录页，完整截取登录窗口]]

首次登录或密码被重置后，系统会要求先修改密码，按页面提示完成即可。连续登录失败次数过多将触发锁定，请稍后再试或联系系统管理员解锁。

## 2.3 工作台

登录成功后默认进入「工作台」。工作台集中展示当前防护概况：受保护应用数、当日请求量、拦截量、待处置事件等关键指标，并提供常用功能入口。

[[SHOT:图2-2 工作台|登录后截取工作台首页，需包含侧边菜单与顶部导航]]

页面左侧为功能菜单，按「应用防护、应用防护策略、访问控制、事件中心、安全态势、报表中心、系统运维、智能安全运营、智能能力管理、系统管理」分组；顶部为面包屑、网关状态指示与当前登录用户信息。

## 2.4 个人中心

点击右上角用户名进入「个人中心」，可查看当前账号信息、修改本人密码、查看本人登录会话并可注销指定会话。

[[SHOT:图2-3 个人中心|进入个人中心页面，展示账号信息与修改密码入口]]

# 第3章 应用防护

## 3.1 网站应用

「网站应用」是接入管理的核心页面，以卡片或列表形式展示全部已接入应用及其防护状态、域名数量、源站健康度。

[[SHOT:图3-1 网站应用列表页|进入「应用防护 > 网站应用」，展示应用列表与「新建应用」按钮]]

### 3.1.1 新建应用

1. 点击「新建应用」，填写应用编码（唯一标识）、应用名称、业务负责人、技术负责人等信息；
2. 选择防护模式：拦截模式（检测到攻击直接阻断）或观测模式（只记录不阻断，用于接入初期观察）；
3. 保存后应用创建成功，处于草稿状态，需完善域名与源站后启用。

### 3.1.2 应用详情

点击应用名称进入详情页，按标签页管理该应用的各项配置：

- 域名管理：维护应用对外域名，支持配置 HTTP/HTTPS 端口、HTTP 跳转 HTTPS；
- 源站管理：维护后端源站地址、端口、权重与健康检查，支持多源站负载分担；
- 代理与头合规：配置 HTTP 头合规（Server、X-Author、X-Powered-By 等响应头处置，X-Frame-Options、HSTS、CSP 等安全头）、HTTP 代理选项（响应缓冲、X-Forwarded-For 覆盖、Host 去端口、关闭压缩协商、302 重定向端口改写）与路径粒度转发（将指定路径前缀转发到指定源站，可剥离前缀）；
- 证书绑定：查看与本应用关联的 HTTPS 证书。

[[SHOT:图3-2 应用详情-域名与源站|进入任一应用详情页，截取域名管理或源站管理标签页]]

[[SHOT:图3-3 应用详情-代理与头合规|截取应用详情页「代理与头合规」标签页，展示头合规与代理配置卡片]]

### 3.1.3 启用与停用

新建应用为草稿状态，配置完善后执行「启用」；停用后该应用流量不再经过防护策略。启用/停用操作需通过配置发布下发网关后生效。

## 3.2 HTTPS 证书

「HTTPS 证书」页面统一管理 SSL/TLS 证书，支持证书上传、查看与删除。

[[SHOT:图3-4 HTTPS 证书列表|进入「应用防护 > HTTPS 证书」，展示证书列表]]

1. 上传证书：点击「上传证书」，填写证书名称，粘贴 PEM 格式的证书文件内容、私钥内容及证书链（可选），保存后系统自动解析证书主体、签发者、有效期与绑定域名；
2. 证书列表展示证书名称、绑定域名、签发者、有效期起止与剩余天数，临近过期的证书将以醒目颜色标识；
3. 已被应用引用的证书不允许删除，需先解除绑定。

## 3.3 配置发布

「配置发布」是将管理面配置下发到防护网关的操作入口。

[[SHOT:图3-5 配置发布页|进入「应用防护 > 配置发布」，展示发布操作区与发布任务列表]]

1. 点击「发起发布」，系统生成发布任务并自动完成配置生成、校验、下发与验证；
2. 发布任务实时显示进度（配置生成 → 发布验证 → 完成），失败时展示失败原因；
3. 发布为幂等操作，重复发布不会产生重复配置；发布期间有全局锁，避免并发发布冲突；
4. 页面下方展示历史发布任务及其结果。

## 3.4 配置版本

「配置版本」页面记录每次发布生成的配置快照，包含版本号、发布时间、发布人、变更摘要与发布结果。

[[SHOT:图3-6 配置版本列表|进入「应用防护 > 配置版本」，展示版本列表]]

点击版本可查看该版本的完整配置详情；当新版本出现异常时，可选择历史正常版本执行「回滚」，系统将按该版本重新生成并下发配置。

## 3.5 网关状态

「网关状态」页面展示防护网关节点的运行状态：在线状态、当前配置版本、最近心跳时间、节点标识等，便于管理员确认配置是否已在网关侧生效。

[[SHOT:图3-7 网关状态页|进入「应用防护 > 网关状态」，展示网关节点状态信息]]

# 第4章 应用防护策略

## 4.1 防护策略

「防护策略」页面管理可复用的策略模板。策略定义了检测模式（拦截/观测）、启用的规则包、攻击类型阈值等参数，一个策略可绑定到多个应用，实现统一防护基线。

[[SHOT:图4-1 防护策略列表|进入「应用防护策略 > 防护策略」，展示策略列表]]

1. 新建策略：设置策略名称、检测模式、规则包组合与阈值参数；
2. 编辑策略：修改后需重新发布方可生效；
3. 策略绑定：在应用详情中将应用关联到指定策略；未绑定策略的应用使用系统默认防护参数。

## 4.2 防护规则库

「防护规则库」页面展示系统内置的全部检测规则（OWASP 核心规则集及各增强规则包），支持按规则包、攻击类型、风险等级、规则 ID 检索。

[[SHOT:图4-2 防护规则库|进入「应用防护策略 > 防护规则库」，展示规则列表与筛选区]]

1. 点击规则可查看规则详情：检测逻辑、匹配目标、默认动作、所属规则包与参考说明；
2. 对特定应用，可通过规则覆盖功能将某条规则在本应用内停用或调整动作（停用/观测/拦截），实现精细化调优。

## 4.3 自定义规则

当内置规则库无法覆盖业务特有的防护需求时，可在「自定义规则」页面编写自有检测规则。

[[SHOT:图4-3 自定义规则列表|进入「应用防护策略 > 自定义规则」，展示自定义规则列表]]

1. 新建规则：填写规则 ID（需在允许号段内）、规则名称、攻击类型、风险等级、检测阶段、检测变量、运算符与匹配值；
2. 动作支持：阻断、观测（仅记录）；
3. 规则保存后经配置发布生效；编辑采用版本乐观锁，防止多人同时修改相互覆盖。

[[SHOT:图4-4 新建自定义规则|打开「新建自定义规则」弹窗，展示各配置项]]

## 4.4 例外策略

「例外策略」用于消除误报：对匹配的请求豁免指定检测。

[[SHOT:图4-5 例外策略列表|进入「应用防护策略 > 例外策略」，展示例外策略列表]]

1. 新建例外：设置匹配条件（域名、URI、请求方法、来源 IP、参数名、Cookie 名、请求头名等）与例外动作（移除指定规则、移除规则标签、移除变量检测、调整评分、仅记录日志）；
2. 支持临时例外：设置生效起止时间，到期自动失效，适用于短期业务变更窗口；
3. 创建例外需勾选「风险已知晓」并填写理由，留痕备查；
4. 例外策略支持启用/停用，删除已启用的例外将立即恢复对应检测。

[[SHOT:图4-6 新建例外策略|打开「新建例外策略」弹窗，展示匹配条件与例外动作配置]]

# 第5章 访问控制

## 5.1 可信代理

当系统部署在 CDN、负载均衡等代理之后时，需在「可信代理」页面登记可信代理的网段，网关将依据登记的可信代理从转发头中还原真实客户端 IP，保证访问控制与频率限制作用于真实来源。

[[SHOT:图5-1 可信代理列表|进入「访问控制 > 可信代理」，展示可信代理列表]]

1. 新建可信代理：填写代理名称、网段（CIDR）、取信头类型（X-Forwarded-For、X-Real-IP、Forwarded 或自定义头）与优先级；
2. 未登记为可信的代理来源，其转发头将被忽略并记录伪造检测事件，防止伪造来源绕过访问控制；
3. 支持设置最大代理链长度，链条超长将按不可信处理。

## 5.2 IP 黑白名单

「IP 黑白名单」页面管理全局级与应用级的 IP 访问规则。

[[SHOT:图5-2 IP 黑白名单|进入「访问控制 > IP 黑白名单」，展示规则列表]]

1. 新建规则：选择名单类型（白名单/黑名单）、作用范围（全局/指定应用）、地址（单个 IP、CIDR 网段或地址段）与优先级；
2. 支持设置生效起止时间，实现定时生效/失效；
3. 白名单命中的请求跳过黑名单与 CC 频率限制检测（仍执行 Web 攻击检测）；黑名单命中的请求直接阻断。

## 5.3 频率与 CC 防护

「频率与 CC 防护」页面管理频率限制策略，用于抵御 CC 攻击与接口滥用。

[[SHOT:图5-3 频率与 CC 防护策略列表|进入「访问控制 > 频率与 CC 防护」，展示策略列表]]

1. 新建策略：设置统计维度（客户端 IP、IP+URI 等）、限速算法（固定窗口/滑动窗口/令牌桶）、URI 匹配方式、阈值（窗口内请求数）与窗口时长；
2. 触发动作支持：直接拒绝、临时封禁（阻断一段时间）、仅观测；
3. 策略可作用于全局或指定应用，同一路径按优先级取最先匹配策略；
4. 策略支持生效时间段设置。

[[SHOT:图5-4 新建频率限制策略|打开新建策略弹窗，展示维度、算法、阈值与动作配置]]

## 5.4 临时封禁

「临时封禁」页面展示当前生效的封禁记录：封禁 IP、触发策略、封禁原因、剩余时间、命中次数。

[[SHOT:图5-5 临时封禁列表|进入「访问控制 > 临时封禁」，展示封禁记录]]

管理员可对误判的封禁执行「解除封禁」，也可手工新增封禁。人工解除后同一 IP 不会立即被同一策略再次封禁（观察期）。

## 5.5 访问控制事件

「访问控制事件」页面记录访问控制模块产生的全部事件：黑白名单命中、CC 限速触发、临时封禁创建与解除、可信代理伪造检测等。

[[SHOT:图5-6 访问控制事件列表|进入「访问控制 > 访问控制事件」，展示事件列表]]

支持按事件类型、时间范围、客户端 IP、应用检索；点击事件可查看完整上下文（请求信息、命中策略、处置动作）。

## 5.6 访问控制版本

访问控制相关配置（可信代理、黑白名单、CC 策略）独立维护版本。「访问控制版本」页面展示每次变更生成的版本快照及发布状态，支持按版本回滚。

[[SHOT:图5-7 访问控制版本列表|进入「访问控制 > 访问控制版本」，展示版本列表]]

# 第6章 事件中心

## 6.1 安全事件

「安全事件」页面集中展示网关检测到的攻击事件，是日常处置的核心入口。

[[SHOT:图6-1 安全事件列表|进入「事件中心 > 安全事件」，展示事件列表与筛选区]]

1. 列表展示事件时间、攻击类型、风险等级、源 IP、目标应用与 URI、命中规则、处置动作；

# 附录A 常见问题

1. 配置修改后没有生效？

配置修改需通过「配置发布」下发网关后生效。请检查「配置发布」页最近任务是否成功，以及「网关状态」页网关节点当前版本是否为最新。

2. 正常业务请求被拦截怎么办？

先在「安全事件」中定位该请求对应的事件与命中规则；确认为误报后，可在事件详情中跳转创建「例外策略」，或在「防护规则库」对该应用做规则覆盖（停用/观测），发布后生效。

3. 接入 CDN/负载均衡后访问控制不生效？

需在「可信代理」中登记前置代理网段，系统才能还原真实客户端 IP；未登记时转发头被忽略，访问控制作用于代理地址。

4. 证书上传失败提示格式错误？

请确认上传内容为 PEM 文本格式（以 -----BEGIN CERTIFICATE----- 开头），私钥与证书匹配；含中间证书的请将证书链一并粘贴。

5. 忘记管理员密码怎么办？

请联系系统管理员在「用户管理」中重置密码；系统管理员账号遗失需由实施人员按运维手册在服务端重置。

6. 智能类功能（安全助手、智能分析等）无法使用？

请先在「智能能力管理 > 模型管理」中配置可用的模型服务并测试连通，然后在「配额与成本」确认未超配额。
