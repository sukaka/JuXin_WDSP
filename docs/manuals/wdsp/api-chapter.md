# 第6章 API 防护

API 防护基于动态学习机制：网关在学习期观察真实流量，自动归纳各接口的路径、方法、参数类型与约束，形成接口模型；管理员确认后转为正式防护基线，对偏离基线的请求执行观测或拦截。本章介绍各功能页面的使用方法。

## 6.1 API 接口资产

「API 接口资产」页面按站点归集系统发现的全部 API 接口，是 API 防护的资产总览。

[[SHOT:图6-1 API 接口资产页|进入「API 防护 > API 接口资产」，展示站点分组与接口列表]]

1. 页面左侧（或上方）为站点列表，展示每个站点（应用）的接口数量；点击站点即可列出该站点下的全部接口；
2. 接口按目录树组织：依据 URI 路径层级展示接口所在的目录结构（如 /test/php/login 归属 test/php 目录），便于按业务模块浏览；
3. 接口列表展示请求方法、路径、所属应用、参数数量、资产状态（待确认/已确认/已忽略）、风险等级与最近活跃时间；
4. 点击接口打开详情抽屉：接口基本信息、路径参数与查询参数约束（类型、是否必填、长度范围）、学习样本数与置信度；
5. 对新发现的接口可执行「确认」（纳入口径基线）或「忽略」（不纳入防护统计）。

[[SHOT:图6-2 接口详情抽屉|打开任一接口的详情抽屉，展示接口信息与参数约束]]

## 6.2 API 模型版本

「API 模型版本」页面展示每个接口学习形成的参数模型及其版本演变：模型版本号、字段集合（字段名、期望类型）、学习窗口、样本量与状态。

[[SHOT:图6-3 API 模型版本列表|进入「API 防护 > API 模型版本」，展示模型版本列表]]

管理员审核学习模型无误后执行「确认」，该版本即冻结为正式模型并随配置发布下发网关，作为偏离检测的基线；发现学习偏差时可放弃当前学习结果重新学习。

## 6.3 学习中心

「学习中心」页面展示 API 动态学习的工作状态：各应用的学习模式（关闭/学习/保护）、学习进度、样本积累情况与待确认事项。

[[SHOT:图6-4 学习中心页|进入「API 防护 > 学习中心」，展示学习状态与进度]]

开始学习：在「API 策略」中将目标应用的 API 防护模式调整为 OBSERVE（观测）并保持流量经过网关，学习中心即开始积累样本并自动归纳接口模型；样本量达标后前往「API 模型版本」确认冻结，再将模式调整为 PROTECT 进入正式防护。

## 6.4 参数模型

「参数模型」页面以参数为维度展示全部已学习参数：参数名、所属接口、出现位置（路径/查询/请求体/请求头）、推断类型、必填性、取值约束与样本支持度。

[[SHOT:图6-5 参数模型页|进入「API 防护 > 参数模型」，展示参数维度列表]]

支持按接口、类型筛选，用于审核学习结果是否符合业务预期。

## 6.5 用途分类

「用途分类」页面按业务用途对接口进行分类标注（如登录认证、支付交易、数据查询、文件上传、管理后台等），分类结果用于差异化防护策略与风险统计。

[[SHOT:图6-6 用途分类页|进入「API 防护 > 用途分类」，展示分类分布与接口归类]]

## 6.6 敏感数据

「敏感数据」页面识别并登记接口请求/响应中出现的敏感字段（身份证号、手机号、银行卡号、Token 等），展示敏感字段类型、所在接口、出现方向与样本脱敏示例。

[[SHOT:图6-7 敏感数据页|进入「API 防护 > 敏感数据」，展示敏感字段清单]]

管理员可确认敏感字段标注，作为敏感数据泄露监测与日志脱敏的依据。

## 6.7 规范对比

「规范对比」页面支持上传接口规范文档（OpenAPI/Swagger），与学习到的实际运行模型自动比对，输出规范外接口、参数缺失、类型不一致等偏差清单。

[[SHOT:图6-8 规范对比页|进入「API 防护 > 规范对比」，展示规范比对结果]]

## 6.8 安全图谱

「安全图谱」页面以图形化方式展示接口、参数、敏感数据与风险之间的关联关系，支持按节点钻取，辅助理解 API 资产全貌。

[[SHOT:图6-9 安全图谱页|进入「API 防护 > 安全图谱」，展示图谱视图]]

## 6.9 调用拓扑

「调用拓扑」页面展示调用方（来源 IP/账号/令牌）与被调接口之间的实际调用关系与频次，帮助发现异常调用路径。

[[SHOT:图6-10 调用拓扑页|进入「API 防护 > 调用拓扑」，展示拓扑视图]]

## 6.10 API 风险

「API 风险」页面汇总系统自动识别的接口风险项：未鉴权接口、敏感数据明文返回、过度数据暴露、写操作缺失限速、参数校验缺失等，按风险等级排序展示。

[[SHOT:图6-11 API 风险列表|进入「API 防护 > API 风险」，展示风险项列表]]

点击风险项可查看风险描述、影响接口、判定依据与整改建议；处置后可标记状态。

## 6.11 影子与僵尸 API

「影子与僵尸 API」页面展示两类生命周期异常接口：

- 影子 API：实际流量中存在但未出现在任何规范文档/登记资产中的接口；
- 僵尸 API：已被标记下线（DEPRECATED）但仍有调用的接口。

[[SHOT:图6-12 影子与僵尸 API 页|进入「API 防护 > 影子与僵尸 API」，展示异常接口列表]]

管理员应核实后将其纳入正式资产或推动下线，消除管理盲区。

## 6.12 API 策略

「API 策略」页面管理 API 动态防护的运行模式与参数。

[[SHOT:图6-13 API 策略页|进入「API 防护 > API 策略」，展示策略配置]]

1. 防护模式：OFF（关闭，流量仅记录访问日志）、OBSERVE（观测，检测并记录偏离事件但不拦截）、PROTECT（防护，对偏离正式模型的请求执行拦截）；
2. 写操作限速：对 POST/PUT/DELETE 等写方法接口的每分钟限速阈值；
3. 模式调整经配置发布后生效；建议按「OBSERVE 学习 → 模型确认 → PROTECT」的路径逐步启用。
