# NG-GQL-02 GraphQL 成本模型冻结设计（阶段 0，2026-10-04）

> 依据：RD_PLAN §7.2。本文件是算法/规则的唯一事实源；实现与测试不得偏离，偏离须回写本文件并升级版本。
> 输入：`gateway/dynamic_security/gqlast` 的有界 AST（NG-GQL-01 已交付）。本模型不复制任何现有产品的复杂度算法，仅参考公开原理自研。

## 1. 成本公式（冻结）

```
cost(selectionSet) = Σ_responseKey [ base(field) + sizeFactor(field) × cost(子选择集) ]
```

- **叶子字段**：子选择集成本为 0，但字段基础成本 `base(field)` 照常计费。
- **非列表字段**：`sizeFactor = 1`。
- **列表字段**：`sizeFactor = approvedListBound(field)`（经批准的上界）。
- **按元素计费的业务成本**：并入对应字段的 `base`（权重配置覆盖默认值）。

## 2. 未决项定案（§7.2 要求阶段 0 冻结的全部细节）

| # | 项 | 定案 | 理由 |
|---|---|---|---|
| D1 | 字段基础成本默认 | 1（`default_field_weight`） | 可解释起点，权重配置覆盖 |
| D2 | 重复字段合并规则 | 按 **response key**（alias 或 name）分组：同一 selection set 内同 response key 的多次出现**只计一次 base**，子选择集成本取各出现的**最大值** | 与 GraphQL 执行合并语义一致（执行时合并同 key 字段）；分别计费会高估正常重复，取 max 不低估恶意分散 |
| D3 | 列表字段默认上界 | `default_list_bound = 100` | 隔离实验候选（RD_PLAN §14.1 量级）；无批准上界的列表**不标未知、按默认上界计**——未知即无法预算，保守可解释优于放弃预算 |
| D4 | 变量（list 型）处理 | **不求值**：一律按对应字段的批准上界计（见 D3/权重覆盖）；不做长度推断 | RD_PLAN §7.1「不能求值的分支采用明确保守上界」 |
| D5 | Introspection | `__schema`/`__type` 根字段权重 50（`introspection_weight`）；`__typename` 按普通字段 1 | 内省放大是最常见滥用面；普通 `__typename` 不惩罚 |
| D6 | 溢出 | 全部乘加做饱和运算（上界 2^62-1）；**溢出即视为超预算**（不绕回小数值） | RD_PLAN §7.2 硬约束 |
| D7 | 单请求预算 | 默认 5,000（`per_request_budget`，按应用可配） | 与主体/租户窗预算分离 |
| D8 | 主体/租户时间窗预算 | 默认 60s / 100,000（`window_budget`）；**匿名请求独立桶**（`anonymous_budget`，默认 60s / 20,000），不与认证主体共享全站桶 | RD_PLAN §7.2 硬约束 |
| D9 | 缓存 | 键 = sha256(规范化文档) + schemaVersion + policyVersion；**变量相关成本不得错误复用固定结果**——本模型变量不求值（D4），成本天然与变量值无关，故可安全缓存；LRU 上限 1,000 条 | §7.2 缓存约束；若未来引入变量求值必须重新评审缓存键 |
| D10 | APQ/持久化查询 | 不自动等于可信文档；只有经审核登记的摘要进可信白名单（白名单属管理面资产，本模型只提供摘要计算口径：sha256(规范化文档)） | §7.2 APQ 约束 |
| D11 | Schema 可选性 | Schema/字段权重缺失时：所有字段按默认权重 + 默认列表上界计算（保守），并在覆盖观测如实标记「无 Schema 权重的保守预算」 | 与 RD_PLAN §7.1「Schema 版本化随策略发布」衔接前的过渡态 |

## 3. 响应映射（执行层输入，GQL-03 接线）

- `COST_OK`：放行（当前成本与预算内）。
- `COST_EXCEEDED_PER_REQUEST`：单请求结构预算超限 → 结构准入失败（GraphQL 协议错误响应，不视为攻击判定）。
- `COST_EXCEEDED_WINDOW`：主体/租户窗预算超限 → 速率失败（与 CC 独立的预算通道，响应码按协议冻结）。
- `COST_UNKNOWN`：不猜、不放过——本模型不产生 UNKNOWN（D3/D4 已消灭未预算分支）；Schema 缺失走 D11 保守预算并在覆盖观测标记。

## 4. 黄金样本（NG-T-G02/G03/G04 锚定）

| id | 样本 | 期望成本语义 |
|---|---|---|
| GQ-C01 | 深度 5 正常订单查询（含 fragment、变量） | 手算成本精确相等（测试内注释推演过程） |
| GQ-C02 | 浅而贵：单字段 × 大列表上界（`users { posts(first: 5000) { id } }`，posts 批准上界 100） | 成本被识别为昂贵（>同形低上界版本） |
| GQ-C03 | 同 response key 重复字段（alias 分叉） | base 计 1 次、子成本取 max |
| GQ-C04 | 大整数链式嵌套（刻意构造 2^k 放大） | 饱和 → 超预算，不绕回 |
| GQ-C05 | 变量 list（`ids: [ID!]` 未给值） | 按默认上界计，不推断 |
| GQ-C06 | 内省根字段 `__schema` | 50 × 子树，显著高于普通查询 |
| GQ-C07 | 缓存：同文档不同 policyVersion | 不复用（重新计算） |
